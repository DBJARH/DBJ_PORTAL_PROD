Custom Styling Guide#

dbjmod CSS and shortcodes for this Hugo site.

Base theme: is PaperMod. From here: https://github.com/adityatelange/hugo-PaperMod.

PaperMod (when used in Hugo based repos) is a git submodule under the site root, at /themes/PaperMod/. Do not edit anything in there. A git submodule is a view onto another repo that you can use as if it were local; edits to it are not ours to make and are lost on update.

dbjmod is the DBJ theme, to be grown gradually out of the overrides below.

Where dbjmod styles live#

Full paths from the site root. Everything in this list is dbj’s, none of it is PaperMod’s.

(note: ‘~’ means root of the site)

~/assets/css/extended/    dbjmod CSS, auto-appended to the PaperMod stylesheet
~/layouts/shortcodes/     dbjmod shortcodes
~/layouts/_partials/      dbjmod head and footer additions

PaperMod’s own CSS is at /themes/PaperMod/assets/css/. Do not edit it.. We said that already.

PaperMod concatenates every .css file in /assets/css/extended/ after its own CSS, so any dbj rule wins without !important. Adding a file is enough — no import, no registration. Irrelevant information but still in here.

Some of the dbjmod files, are in /assets/css/extended/:

Light and dark#

PaperMod stamps data-theme on <html>. Dark rules must be written:

:root[data-theme="dark"] { --your-var: value; }

Not .dark — PaperMod never sets that class, and a rule using it does nothing, silently.

Callouts#

Syntax

{{< callout type="note" >}}
Your content here. Markdown works inside.
{{< /callout >}}

Types

TypeIntensityUse for
notelightestgeneral information
tiplighthelpful suggestions
warningmediumthings to be aware of
importantdarkestcritical information

type defaults to note if omitted. The four are greyscale only, per the repo’s black-and-white rule — intensity carries the meaning, not hue. The hierarchy inverts in dark mode so important stays the strongest.

There is no caution type. The Jekyll guide listed five classes; the shortcode implements four.

Default callout type is note. Omitting type gives note:

Syntax:

{{< callout >}}
No type given
{{< /callout >}}

The effect:

NOTE
No type given

Callout markdown works inside the box. That means: the markdown text you put between the opening and closing callout tags is also treated as markdown, not as literal text. So bold, links, lists inside the box render as bold, links, lists — rather than showing the asterisks.

Syntax:

{{< callout type="tip" >}}
See the [BPT loop](#) for **the full cycle**:

- Business declares the Products
- Technology implements them
{{< /callout >}}

The effect:

TIP

See the BPT loop for the full cycle:

  • Business declares the Products
  • Technology implements them

Plain blockquote#

A normal markdown > quote works as ever; text gets a left alignment and a shaded background. Use it for quotation; use a callout syntax when the box is an aside rather than a quote.

Syntax:

> **DBJ Method** is a sequence of two stages:
>
> **Onboarding** — Establishing foundations of the organisation readiness
>
> **Operating Model** — a Business · Product · Technology loop

The effect:

DBJ Method is a sequence of two stages:

Onboarding — Establishing foundations of the organisation readiness

Operating Model — a Business · Product · Technology loop

Links#

Dark mode uses #6ea8ff — pure blue is unreadable on the near-black ground.
